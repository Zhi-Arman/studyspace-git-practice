# StudySpace Backend / Серверная часть StudySpace

版本 / Версия: 0.1.0 · 日期 / Дата: 2026-10-16 · 状态 / Статус: 基础骨架 / Начальная основа

## 1. 范围 / Область реализации

中文：已提供 FastAPI 基础工程、配置读取、SQLAlchemy 引擎/会话/模型基类及健康检查。尚未实现用户认证、角色授权、资源管理、预约或业务数据库表；此工程不能用于真实预约业务。没有默认用户、密码或密钥，也不会自动执行 `create_all` 或迁移。

Русский: Подготовлены основа FastAPI, чтение конфигурации, движок/сессии/базовый класс SQLAlchemy и проверки состояния. Аутентификация, разграничение доступа по ролям, управление ресурсами, бронирование и таблицы предметной области ещё не реализованы. Система пока не пригодна для реального бронирования. Пользователи, пароли и ключи по умолчанию отсутствуют; `create_all` и миграции автоматически не выполняются.

## 2. 安装与启动 / Установка и запуск

中文：要求 Python 3.13 或 3.14、uv；以下命令从 `studyspace/backend` 执行。项目根目录 `.env` 可由 `.env.example` 复制；不配置 `DATABASE_URL` 时，SQLite 始终位于本目录 `data/studyspace.db` 的绝对路径。

Русский: Требуются Python 3.13 или 3.14 и uv. Команды выполняются из `studyspace/backend`. Файл `.env` в корне проекта можно скопировать из `.env.example`. Если `DATABASE_URL` не задан, SQLite всегда использует абсолютный путь к `data/studyspace.db` в этом каталоге.

```bash
uv sync --frozen --python 3.13
uv run --frozen uvicorn app.main:app --reload --host 127.0.0.1 --port 8000
```

中文：从其他目录启动时，必须保证 Python 可找到 `app` 包（如使用 `--app-dir`）；`.env` 与默认数据库路径不依赖当前工作目录。开发服务器默认仅监听本机。

Русский: При запуске из другого каталога Python должен находить пакет `app` (например, через `--app-dir`). Путь к `.env` и базе данных по умолчанию не зависит от текущего каталога. Сервер разработки по умолчанию доступен только на локальном компьютере.

## 3. 配置 / Конфигурация

| 变量 / Переменная | 默认值 / Значение по умолчанию | 说明 / Описание |
| --- | --- | --- |
| `APP_ENV` | `development` | `development`、`test` 或 `production` / `development`, `test` или `production` |
| `DATABASE_URL` | 绝对路径 SQLite URL / URL SQLite с абсолютным путём | 默认无需设置；自定义 SQLite 父目录需自行创建 / По умолчанию задавать не нужно; родительский каталог для другого SQLite URL создаётся вручную |
| `CORS_ORIGINS` | `["http://localhost:5173","http://127.0.0.1:5173"]` | JSON 字符串数组；开发仅允许本机源 / JSON-массив строк; по умолчанию разрешены только локальные источники |

中文：配置优先级为构造参数、环境变量、项目根 `.env`、默认值；`.env` 不应提交到 Git。跨域不启用凭证传递。后续身份认证方案需另行决策。

Русский: Приоритет конфигурации: аргументы конструктора, переменные среды, корневой `.env`, значения по умолчанию. Файл `.env` не следует добавлять в Git. Передача учётных данных через CORS не включена; схема аутентификации требует отдельного решения.

## 4. 接口 / Конечные точки API

| 路径 / Путь | 含义 / Назначение |
| --- | --- |
| `GET /api/v1/health` | 进程存活，返回 `status`, `service`, `version`；不连接数据库 / Проверка жизнеспособности процесса; возвращает `status`, `service`, `version`; не подключается к БД |
| `GET /api/v1/ready` | 实际执行 `SELECT 1`；成功 200，数据库错误 503，错误响应不包含连接信息 / Выполняет `SELECT 1`; успех — 200, ошибка БД — 503; сведения о подключении не раскрываются |
| `/api/v1/docs` | Swagger UI / Swagger UI |
| `/api/v1/openapi.json` | OpenAPI 描述 / Спецификация OpenAPI |

中文：就绪检查首次访问默认 SQLite 时可能创建空数据库文件，但不会创建业务表。数据库连接成功不代表预约功能已完成或已验收。

Русский: Первая проверка готовности может создать пустой файл SQLite, но не создаёт таблицы предметной области. Успешное подключение к БД не подтверждает реализацию или приёмку бронирования.

中文：三个拟定业务端点的静态契约见 [docs/api/openapi.yaml](../docs/api/openapi.yaml) 与 [DOC-17](../docs/zh-CN/17_API_Contract.md)。它描述后续业务设计，运行中的Swagger仍仅列基础接口。

Русский: Статический контракт трёх проектируемых бизнес-точек: [OpenAPI](../docs/api/openapi.yaml), [DOC-17](../docs/ru-RU/17_API_Contract.md). Он задаёт будущий дизайн; рабочий Swagger содержит только служебные точки.

## 5. 验证 / Проверка

```bash
uv run --frozen pytest
uv run --frozen ruff check .
uv run --frozen ruff format --check .
```

中文：测试使用临时目录中的独立 SQLite，不读取或修改开发数据库。它们验证基础接口契约、空库连接、泛化的数据库失败响应、默认跨域策略和配置优先级。业务测试与用户验收尚未执行。

Русский: Тесты используют отдельную SQLite во временном каталоге и не читают/изменяют базу разработки. Проверяются контракт служебных API, подключение к пустой БД, обобщённый ответ при ошибке БД, политика CORS по умолчанию и приоритет конфигурации. Бизнес-тесты и пользовательская приёмка пока не выполнены.

## 6. PostgreSQL 与容器 / PostgreSQL и контейнер

```bash
uv sync --frozen --extra postgres
# 在根 .env 中配置 / Настройте в корневом .env:
# DATABASE_URL=postgresql+psycopg://USER:PASSWORD@HOST:5432/studyspace
```

中文：保留 PostgreSQL 驱动选项与 SQLAlchemy 抽象；此阶段未验证 PostgreSQL、迁移或预约并发一致性。后续业务模型应采用可迁移类型并引入版本化迁移。`Dockerfile` 为候选容器方式，使用锁文件且排除开发依赖；容器内监听 `0.0.0.0:8000`，宿主映射范围由根 Compose 控制。构建/运行是否验证以实际检查记录为准。

Русский: Предусмотрены драйвер PostgreSQL и абстракция SQLAlchemy. PostgreSQL, миграции и согласованность параллельных бронирований на данном этапе не проверены. Будущие модели должны использовать переносимые типы и версионируемые миграции. `Dockerfile` — предлагаемый способ контейнеризации: установка по lock-файлу без зависимостей разработки, прослушивание `0.0.0.0:8000` внутри контейнера; публикация порта на хосте задаётся корневым Compose. Подтверждение сборки/запуска определяется фактическим журналом проверок.
