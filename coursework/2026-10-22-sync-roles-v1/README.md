## 3 协作规则与同步步骤

3 Правила и порядок синхронизации

规则完整版本保存在本地及线上 COLLABORATION.md。本轮新增规则适用于后续协作，旧指南中直接推送 main 的示例属于上一轮本地演示。

Полная версия правил находится в локальном и онлайн-файле COLLABORATION.md. Новые правила действуют для дальнейшей работы; примеры прямого push в main в старых руководствах относятся к прежней локальной демонстрации.

1 禁止强推，包括 --force、--force-with-lease 和非快进 +refspec。推送被拒绝时停止并与伙伴检查差异。

1 Запрещён принудительный push, включая --force, --force-with-lease и +refspec без fast-forward. При отказе остановитесь и проверьте diff с партнёром.

2 禁止删除本地与远程分支，PR 合并后也保留分支。已实测 GitHub delete_branch_on_merge 为 false。

2 Запрещено удалять локальные и удалённые ветки; после слияния PR они сохраняются. На GitHub проверено delete_branch_on_merge = false.

3 工作前确认目录干净，再 fetch 和 pull --ff-only。已有修改先保存并协调，不用 reset --hard 或 clean 清场。

3 Перед fetch и pull --ff-only убедитесь в чистоте каталога. Сохраните и согласуйте существующие правки; не очищайте их через reset --hard или clean.

4 使用 feature/<topic>、fix/<topic> 或 docs/<topic>，以小范围 PR 交给审查者。作者不得自行批准。

4 Используйте feature/<topic>, fix/<topic> или docs/<topic> и небольшие PR для рецензента. Автор не утверждает собственный PR.

5 冲突处理先确认内容，解决后普通提交，不改写共享历史。审查记录只写实际运行的检查与结果。

5 Сначала согласуйте содержание при конфликте, затем создайте обычный коммит без переписывания общей истории. Записывайте только реально выполненные проверки.

本轮已克隆线上 A/B 工作区，并在审查目录 fetch 后以快进方式 pull。后续在各自目录复核：

Созданы онлайн-клоны A/B; в каталоге рецензента выполнены fetch и pull с fast-forward. Для повторной проверки в своём каталоге:

```text
git status --short
git fetch --no-prune origin
git switch main
git pull --ff-only origin main
git rev-list --left-right --count main...origin/main
git rev-parse HEAD
git ls-remote origin refs/heads/main
```

预期：status 无输出，ahead/behind 为 0 0，HEAD 与 ls-remote 的 main 提交号一致。若目录不干净或出现分叉，应停止同步并协调。

Ожидается: status пуст, ahead/behind равен 0 0, HEAD совпадает с main из ls-remote. При правках или расхождении истории остановите синхронизацию и согласуйте действия.
