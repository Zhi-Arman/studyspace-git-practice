## 3 候选验收标准 / Проектные критерии приёмки

以下 AC 是从当前项目需求与决定推导的课堂测试标准，尚未经教师批准。下列 Markdown 链接指向项目需求源；业务 AC 不因用例编写而视为通过。

Ниже приведены учебные критерии, выведенные из требований и решений проекта; преподаватель их ещё не утверждал. Ссылки Markdown ведут к источнику требований; написание кейса не означает прохождение бизнес-критерия.

<a id="ac-01"></a>
### AC-01 有效预约 / Допустимое бронирование

需求 / Требования: [FR-007](../../../docs/data/requirements.json), [FR-017](../../../docs/data/requirements.json), [BR-001](../../../docs/data/requirements.json)。中文：合格学生能在开放窗口内为一个可用座位创建合规预约，且仅保存一条。Русский: Допущенный студент создаёт одну запись для одного доступного места в разрешённом окне.

<a id="ac-02"></a>
### AC-02 无效区间 / Недопустимый интервал

需求 / Требования: [BR-001](../../../docs/data/requirements.json)。中文：零长、倒序、少于 30 分钟和未对齐整点/半点的请求均拒绝。Русский: Нулевая, обратная, короче 30 минут и не выровненная по получасу запись отклоняется.

<a id="ac-03"></a>
### AC-03 开放与时长边界 / Границы часов и длительности

需求 / Требования: [BR-001](../../../docs/data/requirements.json), [BR-003](../../../docs/data/requirements.json)。中文：默认 08:00–22:00 内最多 14 小时；仅配置全天例外时 24 小时合法，越界拒绝。Русский: По умолчанию окно 08:00–22:00 даёт максимум 14 часов; 24 часа допустимы только при исключении на полный день, превышение отклоняется.

<a id="ac-04"></a>
### AC-04 同座位冲突 / Конфликт одного места

需求 / Требования: [FR-008](../../../docs/data/requirements.json), [BR-002](../../../docs/data/requirements.json)。中文：同座位未取消预约重叠拒绝，相邻半开区间允许。Русский: Пересечение действующих записей одного места отклоняется, соседние полуоткрытые интервалы допустимы.

<a id="ac-05"></a>
### AC-05 同学生互斥 / Непересечение студента

需求 / Требования: [FR-008](../../../docs/data/requirements.json), [BR-004](../../../docs/data/requirements.json)。中文：同学生不同座位重叠拒绝，非重叠多条（含未来）允许。Русский: Пересечение студента на разных местах отклоняется, несколько непересекающихся будущих записей допустимы.

<a id="ac-06"></a>
### AC-06 并发原子性 / Атомарность конкуренции

需求 / Требования: [FR-008](../../../docs/data/requirements.json), [NFR-004](../../../docs/data/requirements.json)。中文：两个用户同时争同座位重叠时段，仅一条提交成功且无重复占用。Русский: При конкурентном запросе одного места и интервала фиксируется только одна запись.

<a id="ac-07"></a>
### AC-07 身份和权限 / Личность и права

需求 / Требования: [BR-006](../../../docs/data/requirements.json), [FR-022](../../../docs/data/requirements.json)。中文：仅 ENABLED+STUDENT+VERIFIED 可预约；PENDING 只读；未知学校来源不得自动通过。Русский: Бронирует только ENABLED+STUDENT+VERIFIED; PENDING имеет чтение; неизвестный источник вуза не даёт автоматического одобрения.

<a id="ac-08"></a>
### AC-08 取消状态 / Состояние отмены

需求 / Требования: [FR-009](../../../docs/data/requirements.json), [BR-005](../../../docs/data/requirements.json)。中文：学生仅在锁后 now<start 可取消本人预约；重复取消幂等；开始后管理员须提供原因。Русский: Студент отменяет своё только при now<start после блокировки; повтор идемпотентен; позже администратору нужна причина.

<a id="ac-09"></a>
### AC-09 业务日边界 / Граница делового дня

需求 / Требования: [BR-004](../../../docs/data/requirements.json), [BR-008](../../../docs/data/requirements.json)。中文：以 Asia/Shanghai 的锁后业务日计算今天至+6；+7 拒绝，客户端设备时区不改变结果。Русский: Горизонт сегодня...+6 вычисляется по Asia/Shanghai после блокировки; +7 отклоняется независимо от часового пояса устройства.

<a id="ac-10"></a>
### AC-10 停用原子性 / Атомарность отключения

需求 / Требования: [BR-007](../../../docs/data/requirements.json)。中文：停用房间时受影响未结束预约在同一事务取消，历史保留，失败则整体回滚。Русский: Отключение помещения и отмена затронутых незавершённых записей атомарны; история остаётся, ошибка откатывает всё.

<a id="ac-11"></a>
### AC-11 健康与就绪分离 / Разделение здоровья и готовности

需求 / Требования: [NFR-007](../../../docs/data/requirements.json)。中文：数据库不可用时健康仍返回 200，就绪返回不泄漏路径的 503。Русский: При недоступной БД здоровье возвращает 200, готовность — 503 без раскрытия пути.

<a id="ac-12"></a>
### AC-12 就绪恢复 / Восстановление готовности

需求 / Требования: [NFR-007](../../../docs/data/requirements.json)。中文：数据库恢复后，无需重启应用即可从就绪 503 恢复到 200。Русский: После восстановления БД готовность меняется с 503 на 200 без перезапуска приложения.

<a id="ac-13"></a>
### AC-13 CORS 预检 / Предварительный CORS-запрос

需求 / Требования: [NFR-003](../../../docs/data/requirements.json)。中文：允许配置的本地前端来源，拒绝未配置来源；这只是浏览器边界，不证明业务授权。Русский: Разрешён настроенный локальный origin, чужой origin отклонён; это браузерная граница, не доказательство бизнес-авторизации.
