# 税额计算器 / Калькулятор налога

## 1 说明 / Описание

根据用户输入的金额和百分比税率计算税额：`amount * rate / 100`。金额必须为非负有限数，税率范围为 0 到 100，含端点。小数使用点号。

Консольная программа вычисляет налог по сумме и процентной ставке: `amount * rate / 100`. Сумма должна быть конечной и неотрицательной, ставка — от 0 до 100 включительно. Десятичный разделитель — точка.

使用 Decimal 计算，最终按 ROUND_HALF_UP 舍入到两位小数。本项目为教学示例；13% 仅是输入示例，不代表法定税率。

Расчёт выполняется через Decimal; итог округляется до двух знаков по правилу ROUND_HALF_UP. Это учебный пример; ставка 13% приведена для демонстрации и не задаёт законодательную норму.

## 2 安装 / Установка

需要 Python 3.10 或更新版本。将本文件夹保存到本地并在终端进入该文件夹；仅使用标准库，无需安装第三方依赖。

Требуется Python 3.10 или новее. Сохраните эту папку локально и откройте её в терминале. Используется только стандартная библиотека, установка сторонних пакетов не нужна.

```bash
cd tax-calculator
python3 --version
```

## 3 运行 / Запуск

必须同时提供 `--amount` 金额和 `--rate` 百分比税率。以下命令查看帮助；完整计算命令见示例。

Обязательны параметры `--amount` (сумма) и `--rate` (ставка в процентах). Справка вызывается командой ниже; команда расчёта приведена в примере.

```bash
python3 tax_calculator.py --help
```

## 4 示例 / Пример

金额为 10000、税率为 13% 时，税额为 1300.00。0.05 按 10% 计算得到 0.005，舍入后为 0.01。

При сумме 10000 и ставке 13% налог равен 1300.00. Для суммы 0.05 и ставки 10% результат 0.005 округляется до 0.01.

```bash
python3 tax_calculator.py --amount 10000 --rate 13
```

```text
Tax: 1300.00
```

## 5 测试 / Тесты

在本文件夹执行以下命令。共四个测试，检查普通计算、零值、半分舍入及非法输入；全部通过时显示 `Ran 4 tests` 和 `OK`。

Выполните команду в этой папке. Четыре теста проверяют обычный расчёт, нулевые значения, округление половины копейки и недопустимые данные. Успешный запуск выводит `Ran 4 tests` и `OK`.

```bash
python3 -m unittest -v test_tax_calculator.py
```

负数、非数字、非有限数以及超出范围的税率会导致命令行报错，退出码为 2。

Отрицательные, нечисловые или неконечные значения и ставка вне диапазона вызывают сообщение об ошибке и код завершения 2.
