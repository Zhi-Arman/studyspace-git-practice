任务 5 场景一 手机应用
Задание 5 Сценарий 1 Мобильное приложение

条件 / Условия
每月发布一次，同时维护旧版本。
Выпуск раз в месяц и поддержка старых версий.

选择 / Выбор
Git Flow

理由 / Обоснование
1 通过 develop 整合开发，feature 分支开发新功能。
  develop используется для интеграции, feature — для новых функций.
2 通过 release 分支准备每月发布，允许稳定版本和日常开发并行。
  Ветка release позволяет готовить ежемесячный выпуск
  параллельно с дальнейшей разработкой.
3 通过 hotfix 处理已发布版本的紧急问题。
  hotfix используется для срочных исправлений выпущенной версии.
4 对受支持的旧版本保留维护分支，将适用修复同步到相关分支。
  Для старых поддерживаемых версий сохраняются ветки сопровождения;
  необходимые исправления переносятся в соответствующие ветки.

结论 / Вывод
固定发布周期及多版本维护适合采用较明确的分支分工。
Фиксированный цикл выпуска и сопровождение версий
обосновывают выбор Git Flow.
