Читатель: студент, который впервые работает с Markdown в VS Code. Выполните задачу A, затем задачу B, чтобы создать, сохранить и просмотреть свой первый Markdown-файл.

菜单和命令采用英文界面名称；中文或俄文界面可选择对应功能。以下操作使用 VS Code 内置功能，无需安装额外扩展。

Названия меню и команд приведены для английского интерфейса; в китайском или русском интерфейсе выбирайте соответствующие пункты. Используются встроенные функции VS Code, дополнительные расширения не нужны.

## 任务 A 打开学习文件夹并创建和保存文件

Задача A Открыть учебную папку создать и сохранить файл

**目标 / Цель**

在学习文件夹中创建并保存 user-guide.md。

Создать и сохранить user-guide.md в учебной папке.

**初始状态 / Начальное состояние**

已安装并启动 VS Code；已准备好学习文件夹，例如 markdown-practice，且知道其位置；文件夹中尚无 user-guide.md。

VS Code установлен и запущен. Учебная папка, например markdown-practice, уже существует, её расположение известно. Файла user-guide.md в ней пока нет.

### 操作步骤 / Порядок действий

1. 选择“File → Open Folder…”（文件 → 打开文件夹）。
   Выберите File → Open Folder… (Файл → Открыть папку).

2. 选中学习文件夹并确认打开；若询问是否信任，对自己创建的文件夹选择信任。左侧 Explorer（资源管理器）应显示该文件夹。
   Выберите учебную папку и подтвердите открытие. Если появится запрос доверия, подтвердите его для созданной вами папки. Её имя появится слева в Explorer (Проводник).

3. 在左侧 Explorer 中右键单击学习文件夹，选择“New File…”（新建文件）。
   В Explorer щёлкните правой кнопкой по учебной папке и выберите New File… (Создать файл).

4. 输入 user-guide.md 并按 Enter；保留 .md 扩展名。
   Введите user-guide.md и нажмите Enter. Сохраните расширение .md.

5. 在编辑区输入下方示例；“#”后保留一个空格，不要输入示例外围的三反引号。
   Введите в редакторе пример ниже. После # оставьте один пробел; тройные обратные кавычки вокруг примера вводить не нужно.

   ```markdown
   # 我的第一份 Markdown 文档
   
   Это мой первый документ Markdown.
   ```

6. 选择“File → Save”（文件 → 保存），或按 macOS 的 Cmd+S、Windows/Linux 的 Ctrl+S。
   Выберите File → Save (Файл → Сохранить) или нажмите Cmd+S в macOS, Ctrl+S в Windows/Linux.

7. 检查左侧学习文件夹下存在 user-guide.md，文件名不是 user-guide.md.txt，且标签页没有未保存标记。
   Убедитесь, что в учебной папке виден user-guide.md, а не user-guide.md.txt, и на вкладке нет индикатора несохранённых изменений.

**结果 / Итог**

学习文件夹中已有保存好的 user-guide.md，文件包含示例标题和正文。

В учебной папке сохранён user-guide.md с заголовком и текстом из примера.

## 任务 B 打开 Markdown 预览

Задача B Открыть предпросмотр Markdown

**目标 / Цель**

在编辑区旁打开预览，并确认标题和正文正确显示。

Открыть предпросмотр рядом с редактором и проверить отображение заголовка и текста.

**初始状态 / Начальное состояние**

任务 A 已完成；user-guide.md 已保存并在编辑区打开，文件中已有示例标题和正文。

Задача A выполнена. Файл user-guide.md сохранён и открыт в редакторе; он содержит заголовок и текст из примера.

### 操作步骤 / Порядок действий

1. 单击 user-guide.md 的编辑区，使该文件成为当前活动文件。
   Щёлкните в редакторе user-guide.md, чтобы сделать этот файл активным.

2. 按 macOS 的 Cmd+Shift+P、Windows/Linux 的 Ctrl+Shift+P，打开命令面板。
   Откройте палитру команд: Cmd+Shift+P в macOS или Ctrl+Shift+P в Windows/Linux.

3. 输入并选择“Markdown: Open Preview to the Side”，按 Enter；编辑区旁应出现预览窗格。
   Введите и выберите Markdown: Open Preview to the Side, затем нажмите Enter. Рядом с редактором появится предпросмотр.

4. 比较源文和预览：第一行应显示为较大的标题，不显示开头的“#”；俄文正文应作为普通段落显示。
   Сравните исходный текст с предпросмотром: первая строка отображается крупным заголовком без начального #, а русский текст — обычным абзацем.

5. 在源文正文末尾添加“ 预览成功 / Предпросмотр работает.”并保存，确认预览也显示这段新增文字。
   Добавьте в конец абзаца исходного текста « 预览成功 / Предпросмотр работает.» и сохраните файл. Убедитесь, что добавленный текст появился в предпросмотре.

**结果 / Итог**

源文与预览并排显示；标题、正文和新增文字均正确显示，修改后的文件已保存。

Исходный текст и предпросмотр видны рядом. Заголовок, абзац и добавленный текст отображаются правильно; изменённый файл сохранён.
