# 测试边界 / Границы тестирования

Version: 0.1.0 · Updated: 2026-10-12

中文：`backend/tests/` 检查健康API、数据库就绪失败和配置；`frontend/src/` 下的测试检查接口状态和界面。当前目录检查双语文档编号、版本及引用一致性。`docs/data/test-cases.json` 是未来业务测试计划，NOT_RUN不代表已通过或已实现。骨架测试只说明初始化基础可用；正式业务验收留待实现后执行。

Русский: `backend/tests/` проверяет API работоспособности, отказ готовности БД и настройки; тесты в `frontend/src/` проверяют состояние API и интерфейс. Текущий каталог проверяет номера, версии и ссылки двуязычных документов. `docs/data/test-cases.json` — план будущих бизнес-тестов; NOT_RUN не означает успешное выполнение или реализацию. Тесты каркаса подтверждают только основу инициализации; приёмка бизнес-функций проводится после реализации.

运行 / Запуск: `bash scripts/check.sh`（项目根目录 / из корня проекта）。
