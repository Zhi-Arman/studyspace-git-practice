# 学习副本边界 / Границы учебной копии

这是从当前 StudySpace 文件系统复制的本地学习快照，不是教师提供的起始项目，也不是 Git 提交或发布版。保留 docs、应用源代码、测试、锁文件及常用本地脚本；未包含原项目 coursework、artifacts、.git、.env、数据库、虚拟环境、node_modules、构建结果或缓存。根 README 内部分历史课程链接可能指向未打包文件；本材料包以父目录 README 为入口。

Это локальный снимок StudySpace, а не архив преподавателя, коммит или релиз. Скопированы docs, исходники приложения, тесты, lock-файлы и основные локальные скрипты. Не включены прежние coursework, artifacts, .git, .env, БД, виртуальная среда, node_modules, сборки и кэш. Исторические ссылки README могут вести к неупакованным файлам; точка входа — README родительского каталога.

本次不启动应用、不运行 Compose、不迁移数据库。学习依赖环境保存在父目录 .venv；仅运行文档静态检查及依赖导入。

Приложение, Compose и миграции не запускаются. Учебная среда находится в родительском .venv; выполняются только статические проверки документов и импорт зависимостей.
