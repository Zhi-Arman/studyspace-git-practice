## 3 Шаблон одного теста

Каждый тест содержит ID, ID требований, название, предусловия, шаги, ожидание, факт, состояние, среду, исполнителя, дату и доказательства. JSON содержит двуязычные названия, предусловия, шаги и предварительные ожидания. Фактические результаты, исполнители, даты и доказательства пока отсутствуют; они добавляются при выполнении.

## 4 Правила сопровождения

Изменение одного теста синхронизируется на двух языках, старый ID не переназначается. После изменения объёма сохраняется запись снятия теста. До утверждения проверяются состояние требований и проверяемые ожидания. Автоматическая проверка реестра проверяет структуру и связи, а не прохождение бизнеса.
