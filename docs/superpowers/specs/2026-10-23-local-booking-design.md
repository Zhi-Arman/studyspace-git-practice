# StudySpace 本地课程版设计 / Проект локальной учебной версии

2026-10-23 · 用户已要求开始开发，并取消真实身份核验、服务器与域名要求。此版本范围覆盖旧 0.3 草案中的相关约束，保留稳定需求编号。
Пользователь поручил разработку без реальной проверки вуза, сервера и домена. Эта область заменяет соответствующие ограничения черновика 0.3 с сохранением ID.

## 1 目标 / Цель

在本机完成可运行、可测试的注册登录→选择房间和座位→预约→查看/取消闭环及管理员管理，最终提交现有 GitHub 仓库。本地账号注册即可预约，不保存真实学号、身份证明或伪造 VERIFIED。界面明确标注本地教学、演示资源。
Локально реализовать регистрацию, вход, выбор места, бронирование, просмотр/отмену и администрирование; передать в существующий GitHub. Достаточно локального аккаунта, без студенческого номера, документов и фиктивного VERIFIED. Интерфейс отмечает учебный режим и демонстрационные ресурсы.

## 2 技术与边界 / Технологии и границы

沿用 React/TypeScript/Vite、FastAPI、SQLAlchemy、SQLite；新增 Alembic 模式迁移。服务只绑定 127.0.0.1。提供本地开发启动和构建后单端口启动；用户追加允许 Docker，Compose 作为本地主启动方式并保留原生脚本；不需要外部字体/CDN、邮件、学校系统、云服务、域名或 HTTPS。现有课程文件保留历史状态，真实学校核验 FR-022/TC-038 撤销且不复用 ID。提醒/签到/违约/使用率仍未来范围。
Используются React/TypeScript/Vite, FastAPI, SQLAlchemy, SQLite и Alembic. Только 127.0.0.1, режим разработки и сборка на одном порту; Docker Compose — основной локальный запуск с сохранением обычного скрипта; без CDN, почты, вузовской системы, облака, домена и HTTPS. FR-022/TC-038 отменены без повторного использования ID. Напоминания, присутствие, нарушения и загрузка остаются будущими.

## 3 身份与权限 / Аккаунты и права

本地用户名 3–32 个 ASCII 字母/数字/下划线，不区分大小写；显示名 1–60 字符；密码 10–128 字符，以随机盐 scrypt 保存。学生自行注册；首位管理员通过显式 CLI 创建，交互输入或私密密码文件，无默认密码。随机会话仅以 SHA-256 存储，12 小时过期，HttpOnly + SameSite=Strict cookie；退出和停用即时失效。写请求需自定义同源请求头并检查 Origin，不允许跨站写入。匿名查询资源；个人记录只能本人访问；管理员管理资源和用户，不能停用/降级最后一位管理员。所有变更重新在写事务中检查账号资格。
Логин 3–32 ASCII буквы/цифры/подчёркивания без учёта регистра, имя 1–60, пароль 10–128 с scrypt и случайной солью. Студент регистрируется сам, администратор создаётся явной CLI-командой без пароля по умолчанию. Случайная сессия хранится только как SHA-256, срок 12 часов, HttpOnly/SameSite=Strict. Выход и отключение отзывают доступ. Запись требует заголовка и допустимого Origin. Ресурсы публичны, личные записи доступны только владельцу; последний администратор защищён, права повторно проверяются в транзакции.

## 4 资源、时间与预约 / Ресурсы, время и бронирование

Room/Seat 两级，软停用，座位编码在房间内唯一；默认开放 08:00–22:00，可配置每日窗口和日期例外（包括关闭）。规则默认提前 7 个上海自然日，可在 1–7 内缩小；时段 30 分钟边界，[start,end)，单次至少 30 分钟、最多 24 小时且在一个业务日及开放窗口内；开始严格晚于事务锁后的 now。UTC 入库，Asia/Shanghai 展示，客户端本地时区无效。
Room/Seat с мягким отключением и уникальным кодом места в комнате; 08:00–22:00 по умолчанию, ежедневное окно и исключения по датам. Окно бронирования 7 дней Шанхая (настройка 1–7); границы 30 минут, [start,end), длительность от 30 минут до 24 часов в пределах дня и расписания. Начало строго позже now после блокировки. Хранение UTC, отображение Asia/Shanghai.

所有业务写操作以 SQLite BEGIN IMMEDIATE 串行事务执行，查同用户/同座位有效重叠后写入；相邻和多条非重叠预约允许。学生仅开始前取消本人预约，管理员取消须原因；重复取消幂等。停用房间/座位/用户或缩短开放窗口时原子取消受影响的未结束预约，恢复启用不恢复已取消记录。
Запись выполняется с SQLite BEGIN IMMEDIATE; проверка пересечений пользователя/места и вставка атомарны. Соседние и непересекающиеся интервалы разрешены. Студент отменяет свою запись до начала, администратор — с причиной; повторная отмена идемпотентна. Отключение ресурсов/пользователя и сужение расписания атомарно отменяют затронутые будущие/текущие записи, включение их не восстанавливает.

## 5 管理、维护与界面 / Администрирование, обслуживание и интерфейс

管理员分页筛选全部预约和用户，维护房间、座位、开放/例外、启停和角色；按统一 as_of 查询业务日创建/取消/未结束数量，不把预约当到场。最小审计只记 actor/目标 ID、动作与时间。预约终结和事件保留 180 天，用户停用 30 天且关联记录过期后匿名化；CLI 提供清理、SQLite 一致性备份、恢复到新文件并先清理过期数据。备份不会自动提交 Git。
Администратор фильтрует записи и пользователей, управляет ресурсами, расписанием, исключениями и правами; статистика даты использует единый as_of без выводов о посещаемости. Минимальный аудит содержит ID, действие и время. Записи/события хранятся 180 дней; пользователь обезличивается после отключения на 30 дней и истечения связей. CLI: очистка, согласованный backup SQLite, восстановление в новый файл с очисткой; backup исключён из Git.

界面采用安静的图书馆风格：暖白、墨绿、琥珀色重点，清晰座位网格与时间摘要。首页可浏览，登录/注册弹层，我的预约和管理员页签；中俄英即时切换、键盘可用、375px 无横向溢出、加载/错误/空态/提交状态齐全。管理员密码不出现在报告、截图或 Git。
Спокойный библиотечный стиль: тёплый белый, тёмно-зелёный, янтарный акцент, сетка мест и сводка времени. Просмотр, формы входа/регистрации, мои записи и администрирование; три языка, клавиатура, 375px без горизонтального переполнения, состояния загрузки/ошибки/пустоты. Пароль администратора не попадает в отчёт, снимки и Git.

## 6 验收与交付 / Проверка и передача

先写失败测试，再实现账号、预约边界与真实 SQLite 并发、管理副作用和维护。前端测登录/预约/取消/语言/错误流程；本地浏览器实走学生与管理流程，检查控制台和移动布局。保留历史 0.3 教学契约，新增运行时 OpenAPI 并核对实现；旧业务 TC 只在有对应实际证据时更新。全套检查必须运行，现有 Ruff 脚本问题按格式整理并验证无行为改变。最后提交开发分支并创建 PR，保留现有 PR #5，不擅自合并 main 或伪造同学贡献。
Тесты пишутся до реализации: аккаунты, границы, реальная конкурентность SQLite, побочные эффекты управления и обслуживание; frontend — вход/бронирование/отмена/язык/ошибки, браузер — реальные локальные потоки, консоль и мобильный вид. Исторический контракт 0.3 сохраняется, runtime OpenAPI сверяется с реализацией; старые кейсы меняются только по свидетельствам. Полный контроль запускается; проблемы Ruff исправляются с проверкой сохранения поведения. Ветка и PR передаются без самовольного слияния main или имитации личных вкладов.
